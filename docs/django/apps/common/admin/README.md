# admin

`isik[django-admin]` - django-object-actions and dalf, with the django extra. Add `django.contrib.admin`,
`dalf` and `django_object_actions` to `INSTALLED_APPS`.

- [base](base.md) — `BaseAdmin`, the base `ModelAdmin` class
- [decorators](decorators.md) — `action`, an admin-action method decorator
