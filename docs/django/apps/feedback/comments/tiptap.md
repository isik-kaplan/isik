# tiptap

Validates Tiptap/ProseMirror JSON documents for `comments(tiptap=True)`, using `prosemirror-py`'s real `Schema` + `Node.check()` rather than a hand-rolled walker - `Node.from_json` alone deserializes invalid nesting (e.g. a `listItem` containing a `heading`) without complaint, only `.check()` catches it. The schema itself is never hand-maintained here: it's read from a JSON file at `settings.FEEDBACK_COMMENTS_TIPTAP_SCHEMA_PATH` (or a per-call `schema_path=`), meant to be generated by the frontend's own Tiptap extensions list. Imported lazily from `comments()` so plain-text comments never require `prosemirror` installed.

## parse_and_check(value, *, schema_path=None)
Parses and validates a Tiptap document dict against the configured schema, raising `ValidationError` on anything wrong (unknown node/mark, missing required attrs, invalid nesting, malformed shape). Returns the parsed `prosemirror.model.Node` on success.

```python
from isik.django.apps.feedback.comments import tiptap

node = tiptap.parse_and_check({"type": "doc", "content": [{"type": "paragraph", "content": [{"type": "text", "text": "hi"}]}]})
```

## get_mentions(value)
Returns the list of `mention` node `id` attrs found anywhere in a Tiptap document - e.g. to notify @mentioned users. Doesn't require the document to be otherwise valid.

```python
tiptap.get_mentions(comment.body)   # -> ["user:1", "user:2"]
```

## TiptapValidator
The model field validator `comments(tiptap=True)` plugs into the generated `body` `JSONField` automatically. Enforces `min_length`/`max_length` against the document's extracted plain text, not the raw JSON.

```python
from isik.django.apps.feedback.comments.tiptap import TiptapValidator

validator = TiptapValidator(min_length=1, max_length=280)
```
