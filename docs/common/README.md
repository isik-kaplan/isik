# common

- [utils/](utils/README.md) - general-purpose helpers (caching, concurrency, error handling, functional/iterable utilities, metaclasses, sentinels, string case conversion).
- [config/](config/README.md) - build typed settings objects from environment variables.
- [settings/](settings/README.md) - settings declared once as class attributes, read from environment variables, code, and (through `isik.cli`) options and questions.
